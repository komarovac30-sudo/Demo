# V8 UX Research Notes

This demo uses public design/UX patterns from established adult-profile and review platforms as **reference only**. No real provider identity, contact data, photos, or third-party review text has been copied into the project.

## Patterns used

- **Slixa:** personality-forward, image-led profiles; prominent verification; direct contact information; polished profile presentation; provider-side stats/control.
- **The Erotic Review (TER):** trust through moderated/verified reviews; review count and reputation as a major decision signal; clear separation between public browsing and richer member-only information.
- **PrivateDelights:** dedicated full-page profiles, review collection/moderation, verification emphasis, and location-oriented browsing patterns.
- **P411:** privacy, trust, verification, discretion, and a closed/private-community tone.

## V8 implementation choices

- Public profile wording changed from generic creator/SaaS language to a premium personal-profile vocabulary: **Gallery, Client Reviews, About Me, Private Collection, Admirers, Direct Call, Private Email**.
- Added discreet mood tags to the profile hero.
- Review section emphasizes moderation and verification.
- Private gallery is visually distinct and access-oriented.
- Creator dashboard language is more personal: **Private Studio, Add to My Gallery, My Gallery, Client Reviews, Profile Insights**.
- Admin remains operational/professional rather than adopting the public-profile tone.
- Added skeleton loading to primary public/private/admin loading paths.
- Demo seed contains 20 entirely original fictional reviews reflecting common trust themes such as communication, profile accuracy, discretion, current media, verification, and respectful interaction.

## Important content note

The 20 seeded reviews are **not real reviews rewritten from third-party sites**. They are original fictional demo reviews created for client presentation so the project does not misrepresent real people or republish third-party user content.
