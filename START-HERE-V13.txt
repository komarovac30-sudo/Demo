VELOURA V13 — PER-VISITOR PRIVATE CHAT

WHAT CHANGED
1. Removed the one-time security banner completely.
2. Visitor chat header now reads:
   Private & Secure Chat. • Messages and photos expire after 24 hours.
3. ES can now send JPG/PNG/WebP photos (max 4 MB) from ES Studio → Messages.
4. Web Chat / Force Text is now configured separately for each visitor conversation.
5. The per-visitor mode control sits beside Block/Unblock in the selected conversation header.
6. Guest chat automatically switches mode after the next poll (normally within ~8 seconds).
