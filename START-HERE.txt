DEPLOY TO YOUR EXISTING PROJECT
1. Extract the ZIP.
2. Copy the CONTENTS of the extracted project into your local GitHub Demo repository.
3. Replace existing app/components/lib/public/supabase files.
4. Keep your existing Vercel environment variables. No secret values are included.
5. BEFORE testing V5 features, run this once in Supabase SQL Editor:
       supabase/update-v5-full-rework.sql
6. For a populated fictional client demo, optionally run:
       supabase/seed-demo-v5.sql
7. GitHub Desktop -> review changes -> Commit to main -> Push origin.
8. Vercel auto-deploys.

PUBLIC-FIRST RULE
A normal Visitor does NOT see a login wall when opening /u/creator.
Authentication appears only after a gated action such as:
- Write a review
- Unlock private/exclusive digital content

IMPORTANT DEMO RULES
- All seeded people, reviews, contact details, artwork, visitor IPs and checkout data are fictional.
- The checkout is DEMO_CHECKOUT; no real payment is processed.
- The demo payment is only for digital exclusive-content access.
- No offline/in-person service booking/payment is implemented.

VISITOR INTELLIGENCE
One captured unique IP/visitor key is consolidated into one top-level visitor row.
Every event remains stored for drill-down, sessions and timeline analysis.
The raw IP is not placed in the detail-page URL.
