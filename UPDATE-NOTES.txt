VELOURA V7 — REVIEW WORKFLOW FIX & CREATOR SUBMISSION
11 September 2026

THIS UPDATE IS BASED ON V6.

1) FIXED REVIEW SAVE ERROR
- Fixed the React form reset issue that could show:
      Cannot read properties of null (reading 'reset')
  after a review was actually saved.
- The form element is now captured before async upload/API work and reset safely after success.
- Success and error messages are no longer shown together for the same action.

2) FIXED ADMIN VERIFICATION FLOW
- Admin verification now has a clear Verify button instead of an icon-only action.
- Verify sets status=PUBLISHED and is_published=true.
- V7 records verified_at and verified_by for the moderation action.
- Success feedback clearly says Review verified and published.
- Pending/Reject/Delete actions have clearer labels and error handling.

3) CREATOR CAN SUBMIT REVIEWS FOR OWN PROFILE
- ES Studio now contains a review submission form.
- Creator can enter reviewer first name, last name, optional reviewer image, 1–5 stars and review text.
- Creator review source is CREATOR.
- Creator submissions are ALWAYS PENDING and hidden publicly until Admin verifies them.
- Creator can see Verified, Pending and Rejected states in ES Studio.
- Reviewer image uploads support preview and Cloudinary upload progress.
- Default reviewer avatar is used when no image is uploaded.

4) PUBLIC REVIEW LABEL
- Removed "Verified demo review".
- Every Admin-verified/published review now displays:
      Verified review

5) DATABASE
If V6 is already installed, run ONCE:
      supabase/update-v7-review-workflow.sql

The V7 migration:
- adds CREATOR as a valid review source,
- adds verified_at,
- adds verified_by,
- adds review moderation indexes,
- keeps direct review writes behind the server-side APIs.

MAIN TEST FLOW

  /dashboard -> Reviews -> Submit for verification
