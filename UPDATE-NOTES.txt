VELOURA — V5 FULL REWORK
Date: 2026-09-11

DESIGN DIRECTION
Cinematic Luxury Dark on the public ES profile.
Clean Studio for User B / ES.
Clean Command Center for User A / Admin.
Detailed analytics are intentionally one level deeper under Visitor Intelligence.

PUBLIC PROFILE
- No initial Visitor login option/wall in the public browsing flow.
- Cinematic cover, avatar, verified state, headline and location.
- Public phone/email contact actions controlled by ES visibility toggles.
- Public media browsing while logged out.
- Anonymous likes for public media via stable visitor key.
- Dedicated private/exclusive content presentation.
- Auth requested only after Write Review or Unlock.
- Visitor review: first name, last name, optional local avatar, 1–5 stars, review text.
- Visitor reviews default to Pending moderation.
- Private-library checkout is simulated and clearly marked as a demo.

ES / CREATOR
- Cleaner Home with a small set of KPIs.
- Local-device avatar and cover photo upload.
- Edit headline, city label, About, public phone/email and visibility.
- Edit exclusive library price/currency.
- Keep Post New Content with PUBLIC / LOCKED visibility.
- Media management on Home.
- Advanced Visitor Intelligence moved out of default Home.

ADMIN
- Home separately shows User Type B Total ES and User Type 3 Total Visitor Accounts.
- Active/disabled ES status.
- Dedicated /admin/creators page.
- Dedicated /admin/reviews page.
- Admin review form has first/last name, optional avatar with default fallback, stars and review text.
- Review moderation: Pending / Published / Rejected + Delete.
- Platform-wide Visitor Intelligence remains available.

VISITOR INTELLIGENCE
- One unique captured IP/visitor key = one top-level row.
- Underlying events are preserved.
- Detail route uses a hashed visitor key, not the raw IP.
- Detail includes location, device, browser, OS, first/last seen, visits, media views, likes, unlocks, 30-minute sessions, event journey and content interest.
- UI states clearly that shared/changing IPs mean the row is an analytics identity, not proof of one physical person.

DATA / API
- New ES presentation/contact fields on profiles.
- Rich review fields and moderation/source state.
- Visitor review API.
- Anonymous/signed-in like handling.
- Payment-ready ledger plus DEMO_CHECKOUT digital-entitlement endpoint.
- Local Cloudinary avatar/cover/reviewer-avatar uploads.
- Admin ES status/verification API.
- Admin review moderation API.

REAL-SITE RESEARCH POLICY
The UI/content model was informed by public patterns found on US directory/review platforms and creator subscription profiles: media-forward profiles, direct contact actions, verification/reputation cues, moderated reviews, mobile-first profiles and gated premium content. The application does NOT copy a real ES name, photo, phone, email or review. Seed content is fictional.

PRODUCTION LIMITS
- DEMO_CHECKOUT is not a live payment integration.
- Payment provider, age/identity verification, legal wording, content policy and production compliance remain launch-time decisions.
- No offline/in-person service booking/payment flow is included.
