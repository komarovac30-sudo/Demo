CreatorSpace Demo - V4 Cinematic + Visitor Intelligence
Date: 2026-09-08

WHAT CHANGED
1. Public creator profile redesigned to Cinematic Luxury Dark.
2. Media is now presented in a premium 2-column visual grid.
3. Exclusive content has a dedicated blurred/private collection experience.
4. Media lightbox, live likes, visitor-location chip, Reviews and About sections retained/refined.
5. Creator dashboard redesigned with KPI cards and unique visitor preview.
6. Super Admin dashboard redesigned with cross-creator visitor intelligence.
7. New Creator route: /dashboard/visitors
8. New Creator detail route: /dashboard/visitors/[visitor-key]
9. New Admin route: /admin/visitors
10. New Admin detail route: /admin/visitors/[visitor-key]
11. One captured unique IP is shown as one visitor entry. Underlying activity events are NOT deleted or merged.
12. Visitor detail shows sessions, complete event timeline, device/location summary and media interest.
13. New events save ip_address + hashed visitor_key inside activity_events.metadata.
14. Raw IP is never used in the URL; the detail URL uses the hashed visitor key.

DATABASE
- V3 likes must already be applied: supabase/update-v3-location-likes.sql
- V4 does not require a destructive schema change.
- Optional performance indexes: supabase/update-v4-visitor-intelligence.sql

IMPORTANT
Historical activity created before V4 may not contain IP data. Those rows use a legacy fallback identity and can display as "Legacy / unavailable IP". New production activity will include the captured IP when Vercel/forwarding headers make it available.

DEPLOY
1. Run V3 SQL first if it was never applied.
2. Optional: run update-v4-visitor-intelligence.sql.
3. Replace your local Demo project contents with this package.
4. Do NOT overwrite your local .env files with secrets from elsewhere.
5. Commit and push to main.
6. Let Vercel deploy automatically.
7. Test /u/creator, /dashboard, /dashboard/visitors, /admin and /admin/visitors.
